# 🧠 AWS Generative AI Developer – Professional (AIP-C01)  
### **30-Day Study Plan (Exam-Aligned)**  
Based on the official AWS AIP-C01 Exam Guide.

---

## 📚 Overview
This repository contains a structured **30-day study plan** designed to help you master the AWS Certified Generative AI Developer – Professional exam.

The plan is aligned with the following exam domains:

1. **Foundation Model Integration, Data, Compliance — 31%**  
2. **Implementation & Integration — 26%**  
3. **AI Safety, Security, Governance — 20%**  
4. **Operational Efficiency & Optimization — 12%**  
5. **Testing, Validation, Troubleshooting — 11%**
